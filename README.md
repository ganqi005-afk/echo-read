# Echo Read

在 Obsidian 里读英文，并且让它读给你听。

不是一个新的阅读器 —— 而是给已有的英文笔记加一层「会听你读」的能力。
正文始终由 Obsidian 自己渲染，插件只在阅读视图里加上交互。

## 能做什么

**阅读**

- 段落自动切成句子，正确处理缩写（`Dr.` / `U.S.`）、小数（`3.14`）、引号内的句号
- 点一句即成为「当前句」，操作条出现在这句话正下方，随滚动跟随
- 拖选任意文字也能操作 —— 标题、列表、表格同样可用
- 只装饰不重绘：加粗、链接等行内格式保持原样

**朗读**

- 点句即朗读；双击一个单词直接听它的发音
- 连续朗读：逐句播下去，高亮跟随并自动滚动
- 系统语音免费且离线，云端合成音色更好

**跟读与评分**（需要语音识别 API）

- 录音 → 识别 → 与原文比对，给出准确度、完整度、流利度、总分
- 差异拆成漏读 / 多读 / 读错三类，能看出该练什么
- 「听我的」回放自己的录音，与原句来回对比

**复习**

- 跟读讲解时，模型挑出的词会自动变成闪卡
- 间隔按艾宾浩斯遗忘曲线安排：1 / 2 / 4 / 7 / 15 / 30 / 90 天
- 卡片以普通 Markdown 存在 vault 里，带 `[[来源笔记]]`，反向链接自动建立

**问 AI**（需要文本模型 API）

- 选中文本提问，四个常见问题一键发出
- 词源解析：六段式输出，同义词在多次解析之间自动轮换

## 安装

**BRAT**（推荐）：安装 BRAT 后添加本仓库地址。

**手动**：把 `main.js`、`manifest.json`、`styles.css` 放进
`<vault>/.obsidian/plugins/echo-read/`，然后在设置里启用。

## 关于 API Key

**朗读与复习不需要任何 API Key** —— 系统语音是免费的，闪卡完全在本地。

需要 Key 的是这三件事：语音识别、云端语音合成、文本模型。三者各自独立配置，
可以只用其中一部分，也可以各用不同的服务商与 Key。

Key 明文保存在 `_lingo/keys.json`。**它会随 vault 同步到云端**，
所以建议为这个插件单独申请一把 Key，便于随时吊销。

## 数据放在哪

| 路径 | 内容 |
|---|---|
| `<附件目录>/echo-read/` | 合成的示范音，跟随 Obsidian 的附件设置 |
| `_lingo/audio-index.json` | 音频索引（记下每段音频对应的原文） |
| `_lingo/cards.md` | 复习卡片 |
| `_lingo/review.md` | 今日复习队列，可随时删掉重建 |
| `_lingo/keys.json` | API Key |
| `_lingo/prompts/` | 三份提示词，可直接编辑 |

笔记本身始终是普通 Markdown，不依赖插件也能正常阅读。

